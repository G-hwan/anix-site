# ANIX

## Overview

ANIX는 2D 애니메이션 촬영/합성 전문 스튜디오.

ani + x 의 조합이며,
x는 다양한 장르와 무한한 가능성을 의미한다.

---

## Main Works

- 중국 애니메이션 촬영/합성
- 게임 PV 제작
- 스킬 영상 제작
- After Effects 기반 합성 작업
- 영상 연출 및 후반 제작
